# Gold 码优选对生成与周期相关对账服务

仅经 HTTP 对外提供 **Gold 码族生成** 与 **周期相关对账**。无前端、无账户、无数据库、
无请求间状态：每笔对账在当次请求内独立完成。

## 数学约定（与实现严格对齐）

- 级数 `n`，码长 `N = 2^n - 1`，码片为双极性 **±1**（GF(2) 位 `b` 映射为 `(-1)^b`，
  故 0/1 域异或 = 码片按位相乘）。
- **偶数 `n` 一律拒绝**，不进入生成。
- `n` 为奇数时旁瓣三值集合钉死为（`t = 2^((n+1)/2)`）：

  ```
  { -1, t - 1, -t - 1 }
  ```

  例：`n=7` 时 `t=16`，集合为 `{-1, 15, -17}`，`N=127`。

- Gold 族共 `N+2` 个成员：两条 m 序列 `m_a`、`m_b`，以及
  `a * T^k b`（`k=0..N-1`，`T^k` 为循环移位，`*` 为码片按位乘）。
- 周期相关在位移 `k` 处为整周期求和，索引按 `N` 取模，**不做截断线性相关**：

  ```
  C_ab(k) = sum_{i=0}^{N-1} a[i] * b[(i+k) mod N]
  ```

- 对账尺子（唯一合格线，不另立汉明重量标准）：
  - 每个成员零位移自相关必须等于 `N`；
  - 非零位移自相关旁瓣、任意两个不同成员的周期互相关，只能落在三值集合内。
- 拒绝发生在生成之前：`n` 越界 / 为偶数、多项式非本原、两序列非优选对，
  都不会产出一族旁瓣超界的码再标合格。

## 级数边界

- 下限：服务钉死 `MIN_N = 7`；
- 上限：服务钉死 `MAX_N = 7`。整族对账穷举全部成员两两、全部位移
  （约 `C(N+2,2) * N` 次打包相关），`n=7` 亚秒至约 1 秒，每增加 2 级数成本约 ×64，
  因此当前只开放 `n=7` 这一个钉死工作点。

## 内置示范档（启动载入、运行期只读）

| 档名 | n | N | f1 | f2 | 三值集合 |
|---|---:|---:|---|---|---|
| `gold-n7-demo` | 7 | 127 | `x^7+x^3+1` (`0x89`) | `x^7+x^3+x^2+x+1` (`0x8F`) | `{-1, 15, -17}` |

启动时对每个档做本原性 + 优选对校验，构建即失败（fail fast）。

## HTTP 接口

### `GET /health`
### `GET /presets` — 列出已登记档
### `POST /reconcile` — 按档或按显式多项式生成并对账

按档：
```json
{ "preset": "gold-n7-demo" }
```

显式多项式（`n` 必填；多项式接受整数、`"0x.."`/`"0b.."`/`"0o.."` 掩码字面量，
或 `"x^7+x^3+1"` 形式）：
```json
{ "n": 7, "polynomialA": "x^7+x^3+1", "polynomialB": "0x8f" }
```

成功响应含：`N`、`codeLength`、`threeValueSet`（含 `t` 与公式串）、
`polynomials`、优选对互相关取值、族大小、零位移值、三值旁瓣集合、
`outOfRangeShifts`（超界位移明细，最多 50 条）、总数与 `qualified`。

### 带类型错误

| code | HTTP | 触发 |
|---|---:|---|
| `INVALID_REQUEST` / `INVALID_JSON` | 400 | 请求体非对象、字段缺失、混用 preset 与内联 |
| `EMPTY_POLYNOMIAL` | 400 | 空/零多项式 |
| `INVALID_POLYNOMIAL` | 400 | 无法解析为 GF(2) 多项式 |
| `UNKNOWN_PRESET` | 404 | 未知档名（响应附 `details.known`） |
| `EVEN_DEGREE` | 422 | `n` 为偶数 |
| `DEGREE_OUT_OF_RANGE` | 422 | `n` 超出钉死区间 |
| `DEGREE_MISMATCH` | 422 | 多项式次数 ≠ n |
| `NOT_PRIMITIVE` | 422 | 多项式不可约或阶不为 `2^n-1` |
| `NOT_PREFERRED_PAIR` | 422 | 两条 m 序列互相关不恰好为三值集合（响应附观测值） |

## 运行

```bash
npm install
npm start                 # 默认 :3000，可用 PORT 覆盖
npm test                  # node --test，54 个用例
```

容器：

```bash
docker build -t gold-reconciler .
docker run --rm -p 3000:3000 gold-reconciler
```

## 模块划分（按职责拆分）

```
src/
  threeValue.js       三值集合（t 与公式，钉死）
  gf2.js              GF(2) 多项式：Rabin 不可约 + 本原阶判定
  polynomialParser.js 本原多项式多种写法解析
  errors.js           带类型错误
  msequence.js        Galois LFSR m 序列、码片乘/取反/循环移位
  preferredPair.js    优选对判定（全周期互相关 == 三值集合）
  family.js           Gold 族 N+2 成员生成
  correlation.js      打包位周期相关（popcount），附标量参考实现
  reconcile.js        生成前门禁 + 整族三值对账
  presets.js          档表（启动校验、运行期只读）
  app.js              Express 路由与错误汇流
server.js             进程入口
test/                 数学对拍、不变量、拒绝路径、HTTP、并发隔离
```

## 对拍与不变量（测试覆盖）

- 打包位相关引擎逐位移与标量整周期相关一致（含随机 ±1 码字）；
- m 序列自相关为 `{N, -1}` 两值（不作为 Gold 合格线）；
- 示范档零位移 = 127、全部旁瓣在 `{-1,15,-17}` 内；
- 码片全反，自相关序列不变；
- 循环移位后自相关取值集合不变；
- 同族换另一对成员，互相关仍在同一三值集合；
- 非本原 / 非优选对 / 偶数 / 越界 / 空多项式 / 未知档名全部被拒；
- 多笔对账并发，各自独立、结果互不串扰。
